<a id="proje-hakkinda"></a>
## 📜 Proje Hakkında  
Bu proje, satranç tahtasında N adet vezirin birbirini tehdit etmeden yerleştirilmesi problemini çözer.  
Tek iş parçacıklı ve çoklu iş parçacıklı çözümlerle performans karşılaştırması yapılır.

<a id="ozellikler"></a>
## ⚡ Özellikler  
- ✅ N-Queens problemini çözme  
- ✅ Tek iş parçacıklı çözüm  
- ✅ Çoklu iş parçacıklı (thread) çözüm  
- ✅ Çözüm sayısını hesaplama  
- ✅ Çözüm süresini ölçme ve karşılaştırma  

<a id="kullanim"></a>
## 💻 Kullanım  
1. 📂 Projeyi Visual Studio veya dotnet CLI ile açın.  
2. ▶️ Programı çalıştırın.  
3. 🔢 Konsolda çözmek istediğiniz N sayısını girin.  
4. ⏳ Program, çözümleri hesaplayacak ve süreleri karşılaştıracaktır.
